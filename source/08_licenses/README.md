- JPEG 解码器及独立 C 模型来自本地已使用的 `ultraembedded/core_jpeg` 副本，原版权头与 Apache-2.0 许可保留；完整本地副本在 `07_dependencies/jpeg_reference_root/vendor/core_jpeg`，许可另见本目录 `core_jpeg_LICENSE`。
- Big Buck Bunny 原片 ©2008 Blender Foundation，素材记录 [BBB_SOURCE.json](BBB_SOURCE.json)；来源为 [480p片段仓库](https://github.com/bower-media-samples/big-buck-bunny-480p-30s)，许可与署名参考 [Blender 项目说明](https://peach.blender.org/about/)。本版截取10–30秒、居中裁切640×480、转15fps、编码JPEG并添加可见署名；原视频和生成记录已保留。
- 板一示例中用户提供的照片与景物素材来源分别保留在 `03_media/board1_examples/sources/photos` 和对应 DELIVERY 元数据。本地交付不改变原有权利归属。
- 赛题基础工程、TD厂商IP与加密模块保留原文件、版权声明及使用条件；其存在不代表整个交付包采用Apache-2.0。TD等工具安装程序不在本包内。
- FPGAmp、nanoSPC仅作为本轮打包结构参考，并没有把它们整库并入本工程，也没有把其项目许可证套用于本包。

本包为用户本地完整交付，未创建GitHub仓库或上传任何文件。
