# 板一相册：五档周期与多方式控制

固件：`HX4S20C_BOARD1_ALBUM_PERIOD_8EB7D133.bit`，已通过用户实板验收。下载选择 **PROGRAM_SRAM、5MHz**，使用板一配套照片/音频相册卡。

## 按键操作

| 实物按键 | 动作 |
|---|---|
| KEY1 | 复位；等待时间恢复 1 秒，自动轮播关闭 |
| KEY2（B2） | 手动下一张 |
| KEY3（B1） | 循环切换相册、亮度、对比度、音量、音频条、音乐播放六种模式 |
| 相册模式下 KEY4（C1）短按松开 | 自动轮播开/关 |
| 相册模式下 KEY4 长按约 1.2 秒 | 等待时间前进一档：1 → 2 → 5 → 10 → 30 → 1 秒 |

代码逻辑信号 `key2` 对应实物 KEY4。每次长按切换一档，松开后可继续长按切档；自动轮播开关由短按控制。亮度、音量等模式下，KEY4 执行对应模式的调节动作。

设置 5 秒的示例：复位并等待首图显示，长按 KEY4 后松开两次（1→2→5），再短按松开 KEY4 开启自动轮播。相册至少配置两张照片。修改等待时间后重新计时，复位后恢复默认值。

## 相册显示与控制

所选秒数为照片提交显示且加载空闲后的停留等待时间；随后执行下一张加载、切换与淡入。暂停控制后续自动加载，当前加载流程完成后保持显示。

支持手动下一张、手机红外，以及板二语音的下一张、暂停、继续命令；相册与伴音通过各自的数据通路协同运行。

## 下载与使用

1. 插入板一相册卡，按接线说明连接设备，将本目录固件下载到 SRAM。
2. 下载及复位时松开 KEY2/KEY3/KEY4，待首张照片显示后操作。
3. 在相册模式使用短按控制轮播、长按选择等待时间，也可使用语音和红外控制。

## 验证数据

周期与手势单元验证包含 48,076 条检查；相册、音频、UART、UI 与 NEC 控制具有对应仿真资料。最终构建 setup +0.582ns、hold +0.004ns，STA 覆盖率 99.96%。用户实板验收记录见 `../ACCEPTANCE_UPDATE.md`，工程数据见 `../ENGINEERING.md`。
