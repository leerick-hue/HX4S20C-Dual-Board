# 板二：640×480 视频与语音控制

固件 **6F5DD197** 已通过用户实板验收，提供 JPEG 视频播放、麦克风采集、语音模板注册与板间命令通信。

配套视频为 **640×480、15fps、20 秒、300 帧**的静音片段。RGB565 双帧缓存承接解码像素，HDMI 输出为 **1280×720@60Hz**，画面位于左320、上120的原生居中窗口。软件仿真稳态换帧间隔约 66.7ms。

## 配套文件

- 固件：`HX4S20C_BOARD2_VIDEO_480P15_6F5DD197.bit`。
- TF 卡镜像：`CARD_BBB_20s_640x480_15fps.img`。
- 素材软件预览：`BBB_480p15_preview.mp4`。
- 文件校验：`SHA256SUMS.txt`。

## 写卡与播放

1. 备份 TF 卡内所需文件，将卡接入读卡器，选择配套镜像按裸扇区方式整卡写入并校验。写入会覆盖卡内内容；确认目标为 TF 卡。系统提示格式化时选择取消。
2. 安全弹出卡并插入板二，连接 HDMI，将显示器切换至对应输入。
3. 上电并下载本目录固件，选择 **PROGRAM_SRAM、5MHz**。
4. 短按 KEY1 复位，等待视频启动，即可观看居中画面与连续循环播放。

## 语音操作

KEY2 注册“下一张”，KEY3 注册“暂停相册”，KEY4 注册“继续相册”。每次上电、复位或重新下载后进行注册：先安静 2 秒，松键约半秒后说出对应命令，说完安静至少 1 秒；三类模板录齐后进行识别。

板间通信为 115200/8N1，具有 CRC、回执、重试与重复命令管理。板载 USB 串口支持 1Mbps 音频诊断，接线见 `../../05_docs/WIRING_CURRENT.md`。

## 实现与验证

- 每个帧缓存银行为 153600 个 32 位字，双银行共 1228800 字节，按 JPEG 原始坐标组织像素。
- 48kHz 时间戳每帧推进 3200 个样本。
- 完整视频链路和视频/语音/命令共存仿真具有对应数据记录，JPEG 样本具有独立 C 参考比较。
- 最终构建 setup +0.200ns、hold +0.021ns，8 个时钟，STA 覆盖率 99.99%。

视频采用 [Big Buck Bunny 480p 素材](https://github.com/bower-media-samples/big-buck-bunny-480p-30s)，原片 ©2008 Blender Foundation，采用 [CC BY 3.0](https://peach.blender.org/about/)。素材取 10–30 秒，居中裁切至 640×480、转换为15fps、添加署名并编码为 baseline JPEG。
