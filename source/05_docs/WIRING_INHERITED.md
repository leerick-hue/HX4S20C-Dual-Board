# 当前双板接线：8EB7D133 + 6F5DD197

本表按冻结固件的约束和本会话接线说明整理。先断电再插线。J1/J2 是板上排针名称；F13、D14 等是 FPGA 球号，不能当排针脚号。以插座三角/数字1定位脚号，不凭左右猜。

## 两板通信：三根线

| 发送/参考端 | 接收/参考端 |
|---|---|
| 板二 J1.1，D14，TX | 板一 J1.1，D14，RX |
| 板一 J1.2，G11，ACK TX | 板二 J1.2，G11，ACK RX |
| 板二 GND（已确认的 J2.12） | 板一 GND（J1.12） |

两板按原方式各自供电，板间只连接上述信号与共地。通信为115200、8N1，带CRC、回执和重试。板二板载USB串口另用于1Mbps音频诊断，二者不能混作同一串口。

## 板二 INMP441

| 麦克风端 | 板二连接 |
|---|---|
| VDD/VCC | J1.29，3.3V |
| GND | 使用已确认的 GND 接点，参考 J2.12 |
| L/R | GND，选择左声道 |
| SCK | J1.4，F13 |
| WS | J1.8，J13 |
| SD | J1.10，L14 |

麦克风和板间通信共用已确认的地参考，接地接点以当前实物已验证的连接为准。

板载 CH340 经USB接电脑，调试TX为D12；不需要额外串口模块。先用 `py -3 -m serial.tools.list_ports -v` 找实际COM号。采样脚本为 `04_tools/capture_pcm.py`。

## 板一 TSOP38238 裸三脚红外接收头

凸起接收面朝向自己、三脚朝下，从左到右为 OUT、GND、VCC。针序仅适用于TSOP38238裸器件；带小板或其他型号按其丝印/规格核对。

| 接收头 | 板一连接 |
|---|---|
| 左 OUT | J1.4，F13 |
| 中 GND | J1.12，GND |
| 右 VCC | J1.29，3.3V |

板一红外接收头 GND 使用 J1.12，电源与信号按 3.3V 方案连接。原厂针序参考：[TSOP382 数据手册](https://www.vishay.com/docs/82491/tsop382.pdf)。
